# Security Policy

We take the security of **daimax-appbench** seriously. This document
describes which versions are supported and how to responsibly report a
security vulnerability.

## Supported Versions

The following versions currently receive security updates:

| Version | Supported          |
| ------- | ------------------ |
| 0.2.x   | :white_check_mark: |
| < 0.2   | :x:                |

## Reporting a Vulnerability

**Please do NOT open a public GitHub issue for security vulnerabilities.**
Publicly disclosing a vulnerability before a fix is available puts all users at
risk.

Instead, report vulnerabilities privately by emailing:

**security@daimax-appbench.dev**

Please include as much detail as possible, such as:

- A description of the vulnerability and its potential impact.
- Steps to reproduce or a proof of concept.
- Affected version(s) and environment details.

## Response Time

- We will **acknowledge your report within 72 hours** of receiving it.
- We will provide an **initial assessment and a fix timeline within 7 days**.

## Disclosure Policy

We follow a **coordinated disclosure** process. We will work with you to
understand and resolve the issue promptly. Details of the vulnerability will
only be disclosed publicly **after a fix is available** and users have had a
reasonable opportunity to update.

We appreciate your efforts to responsibly disclose security issues and help
keep our users safe.
